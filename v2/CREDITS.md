Texture `hardwood2_*`, `grasslight-big`, `brick_*` dal repository three.js (MIT).

Librerie: [three.js](https://threejs.org) r170 (MIT), [N8AO](https://github.com/N8python/n8ao) (CC0), postprocessing (Zlib), esbuild.

Rigenerare il file: `cd v2 && npm install && node build.mjs`.
